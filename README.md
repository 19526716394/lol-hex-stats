# HEXSTATS · 英雄联盟 海斗与斗魂数据榜

英雄联盟**海克斯大乱斗**（ARAM Mayhem）与**斗魂竞技场**（Arena）的英雄胜率、海克斯胜率、平均名次与推荐出装榜单。云端自动刷新、多源交叉校验，另有桌面助手可常驻查询。

## 在线访问

直接打开：

```text
https://19526716394.github.io/lol-hex-stats/
```

数据由 GitHub Actions 每 30 分钟自动抓取、校验并部署，不需要电脑常开，也不需要本地服务。失败时保留上一版快照。

仓库与运行记录：

- 代码与数据：https://github.com/19526716394/lol-hex-stats
- Actions：https://github.com/19526716394/lol-hex-stats/actions

桌面助手（可选，托盘常驻、悬浮查询）：

```text
E:\软件\LoLHexAssistant\启动助手.bat
```

## 本地运行（可选）

1. 双击 **`启动.bat`**。
2. 浏览器会自动打开 `http://127.0.0.1:8765/`。
3. 关闭标题为 **HEXSTATS 服务** 的 PowerShell 窗口即可停止。

首次打开如果还没有数据，双击 **`刷新数据.bat`** 拉取一次；之后服务默认每 30 分钟自动刷新（海斗 + 斗魂）。本地页面的 **刷新数据** 按钮可立即触发刷新；云端静态页面不显示该按钮。

## 页面使用

- 首屏优先展示**搜索栏和胜率榜**；版本号、有效对局、英雄出场等统计移到底部“数据版本、样本量与口径（次要）”，默认折叠。
- 搜索支持英雄中文名、称号、英文 ID、拼音和常用外号，例如“盲僧 / LeeSin / 李青”“瑞天帝 / 瑞兹”“卡牌 / 崔斯特”；也支持少量错别字（如“盲憎”）与海克斯效果关键词。
- 点击英雄进入详情，优先展示**版本成型思路**与**高胜率海克斯 × 出装组合**；单件海克斯/装备榜单放在组合之后。斗魂会展示“同套推荐搭配”，但明确标注为分别排序、非联合胜率。

## 统计口径

- **海斗**：全体玩家、normal 全量样本，统计窗口约一周，国服 7 区合并。
- **海斗英雄胜率**：英雄出场对局中的获胜比例；选取率为每队每位置的出现率。
- **海斗海克斯胜率**：携带该海克斯的对局胜率。
- **相对提升（delta）**：`(Σ胜场 − Σ(场次 × 同英雄平均胜率)) / Σ场次 × 100`，用于剔除英雄本身强度的影响。
- **海克斯搭配组合**：来自 ARAMKit 趣味榜单的真实双海克斯联合样本，展示组合胜率、基准胜率与相对变化；不把单卡胜率相乘推算。该榜未公开每组样本量，且为单源，因此不评信心等级，组合属稀有事件，仅供参考。
- **斗魂**：8 人乱斗，前二名视为“胜”；默认按平均名次排序（越低越好），同时给出前二率、第一名率、选取率与禁用率。
- **斗魂海克斯**：按前三率、平均名次、第一名率、选取率统计；不把不同稀有度强行混成一个“胜率”口径。
- **斗魂出装**：ggez 推荐强化/成装，按前三率与选取率展示；当前覆盖胜率榜前 30 名英雄，低样本不硬凑。
- **属性与效果**：悬浮海克斯/装备优先显示游戏内效果、装备属性与被动；胜率、选取率等统计降为一行小字。点击装备可查看完整属性、被动与价格，点击海克斯可查看完整效果与适配英雄；场次、覆盖数量等次级信息折叠在“次要”区域。
- **英雄详情组合**：优先展示真实联合样本的海克斯 × 出装组合（同一海克斯下的成装表现），以及该英雄最佳海克斯命中的双海克斯协同；斗魂没有联合样本，只展示分别按前三率排序的“同套推荐搭配”，不伪造组合胜率。
- **信心等级**：
  - A：样本充足，且至少一个独立来源偏差 ≤ 2 个百分点（斗魂为排序接近）。
  - B：样本中等，或偏差 ≤ 4 个百分点（斗魂为排序偏差较小）。
  - C：低样本或来源分歧较大，仅作参考。
  - 单源：仅主源覆盖，未能完成第二来源核对。

## 常见问题

**打不开页面 / 端口被占用**
先关闭旧的 `HEXSTATS 服务` 窗口，再重新双击 `启动.bat`。端口可以在 `serve.ps1` 顶部的 `-Port` 参数修改，同时要改 `启动.bat` 里的地址。

**页面显示“没有读到数据”**
运行 `刷新数据.bat`，确认 `data/snapshot.json` 已生成；查看 `logs/refresh.log` 中的错误信息。

**刷新失败**
多数是网络问题。脚本优先走 jsDelivr CDN，失败会回退本地缓存；GitHub API 未登录时可能 403，但版本发现已改用 GitHub 网页目录，不影响正常刷新。

**部分英雄没有出装**
斗魂出装只覆盖胜率榜前 30 名，以控制抓取量并保证样本；排名靠后的英雄详情会提示暂未覆盖，不会用低样本硬凑。海斗出装则覆盖全部有足够样本的英雄。

**数据为什么不是“秒级实时”**
这类逐局统计没有公开的秒级接口。本项目采用“每 30 分钟自动抓取 + 页面轮询 + 手动刷新”的组合，兼顾时效与对数据源的请求压力。

**能商用吗**
主源 AramHex 使用 CC BY-NC 4.0 许可；斗魂数据归 ggez.gg / Riot Games。本项目按个人/团队非商用研究用途使用，并在页脚署名。商用请自行联系数据源作者获取授权。
